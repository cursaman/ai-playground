# 나의 프롬프트 모음

1주차에 직접 실행하고 개선한 프롬프트를 이곳에 기록합니다. 대괄호 안의 내용을 상황에 맞게 바꿉니다.

## 어려운 개념 배우기

```text
[배우고 싶은 개념]을 처음 배우고 있어.
내 현재 수준은 [수준]이고, 목표는 [목표]야.

1. 쉬운 정의
2. 일상적인 비유
3. 구체적인 예시
4. 자주 하는 오해
5. 이해도를 확인할 문제 3개

순서로 설명해줘. 확실하지 않은 내용은 추측하지 말고 표시해줘.
```

## 글 검토하기

```text
아래 글을 [독자]가 쉽고 정확하게 이해할 수 있도록 검토해줘.
맞춤법뿐 아니라 논리의 흐름, 모호한 표현, 근거가 필요한 주장도 확인해줘.

먼저 개선할 점을 표로 정리하고, 그다음 원문의 의미를 유지한 수정본을 작성해줘.

[검토할 글]
```

## 실행 계획 만들기

```text
나는 [목표]를 이루고 싶어.
현재 상황은 [상황]이고, 사용할 수 있는 시간과 자원은 [시간과 자원]이야.

목표를 작은 단계로 나누고 각 단계의 할 일, 예상 시간, 완료 기준을 표로 만들어줘.
시작하기 전에 부족한 정보가 있다면 꼭 필요한 질문부터 해줘.
```
